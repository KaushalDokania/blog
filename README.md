# blog

Source for my personal website and blog [https://kaushaldokania.github.io/](https://kaushaldokania.github.io/)

Built with [Hugo](https://gohugo.io/) and the [hello-friend-ng](https://github.com/rhazdon/hugo-theme-hello-friend-ng) theme. GitHub Actions builds the site and publishes it to [kaushaldokania.github.io](https://github.com/KaushalDokania/kaushaldokania.github.io). See [build.md](build.md) for how to write and publish a post.
